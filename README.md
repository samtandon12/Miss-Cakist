# Miss Cakist — Homemade Cakes & Bakery Website

A premium, modern, food-delivery style cake ordering website built for **Miss Cakist**, a local bakery business based in Muzaffarpur, Bihar.

Designed with React, Vite, TypeScript, and Tailwind CSS. Built to deploy seamlessly on Vercel.

## ✨ Features

- **Food-Delivery Style Order Experience**: Zomato/Swiggy inspired clean interface with quantity controls (`- 1 +`) directly on cards.
- **Persistent Cake Box (Cart)**: Uses `localStorage` to preserve items across page reloads.
- **Dynamic WhatsApp Checkout**: Converts cart items, weight selections, delivery address, and landmarks into pre-filled WhatsApp messages.
- **Featured Cake Showcase**: Highlights the signature **Royal Rasmalai Fusion Cake** with configurable "Price on Request".
- **Local SEO & Structured Data**: Includes JSON-LD (`LocalBusiness`, `Bakery`, `BreadcrumbList`, `Product`), OpenGraph tags, dynamic meta titles/descriptions, `robots.txt`, and `sitemap.xml`.
- **Responsive Mobile Experience**: App-style horizontal category scroller, mobile search overlay, filter modal, and sticky bottom cart bar.

## 🛠️ Local Development

```bash
# Clone repository
git clone https://github.com/samtandon12/Miss-Cakist.git

# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```
